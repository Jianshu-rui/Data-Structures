# 递归函数设计技巧

## 一、数学归纳法

`Step1`: 验证P(1)成立

`Step2`: 证明如果P(k)成立，那么P(k+1)也成立

`Step3`: 联合Step1和Step2，证明由P(1)->P(n)成立

与数学归纳法对应的是结构归纳法

## 二、结构归纳法——递归函数设计的三个重要部分

1. 重要：给 [递归函数] 一个明确的语义
2. 实现边界条件时的程序逻辑 `P(1)`
3. `假设`递归函数调用返回结果是正确的 `P(k)`，实现本层函数逻辑 `P(k+1)`

## 三、简单例子：递归求阶乘

```cpp
int f(int n) {
    if (n == 1) return 1;
    return f(n - 1) * n;
}
```

1. `f(n)`: 代表n的阶乘
2. `if (n == 1) return 1`: 边界条件，是`P(1)`的逻辑
3. `return f(n - 1) * n`: 是`P(k)`和`P(k+1)`的逻辑，假设`f(n - 1)`是正确的，实现`f(n)`
